Les prérequis de cet atelier sont volontairement réduits au minimum.

## Ce que vous apportez
- Un ordinateur portable avec un navigateur récent.
- Un accès à un **cluster OpenShift 4.19 ou ultérieur** sur lequel le Helm chart est déjà déployé (nous le fournissons le jour de l'événement).
- Savoir vous servir d'un terminal, sans plus. Aucune expérience de Kubernetes n'est nécessaire.

## Ce que nous fournissons
Sur place, nous vous donnons accès à un cluster OpenShift préconfiguré, sur lequel la gateway OpenShell tourne déjà. Lors d'un atelier à plusieurs participants, vous recevez un lien d'accès personnel qui vous attribue, sur un cluster partagé, votre propre gateway, votre namespace d'agent et votre namespace de démo. Inutile d'avoir un compte cloud ou une carte bancaire.

<Callout type="tip" title="Tout est déjà déployé">
Le cluster, la gateway et ce site d'atelier sont déjà en service. Un navigateur suffit pour commencer.
</Callout>

## Ce dont vous n'avez pas besoin
- D'un GPU : le modèle est déjà servi (dans ce lab, il s'agit du modèle `nemotron`, publié par OpenShift AI Models-as-a-Service).
- D'une installation locale de Kubernetes ou d'OpenShift : tout tourne sur le cluster.
- D'une connaissance approfondie de YAML : le déploiement tient en un seul Helm chart.
