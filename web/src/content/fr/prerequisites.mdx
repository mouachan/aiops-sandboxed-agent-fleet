Ce workshop demande volontairement très peu de prérequis.

## Ce que vous apportez
- Un ordinateur portable avec un navigateur récent.
- Un accès à un **cluster OpenShift 4.19+** sur lequel le Helm chart est déjà déployé (nous le fournissons pendant l'événement).
- Une aisance de base avec le terminal. Aucune expérience Kubernetes requise.

## Ce que nous fournissons
Pendant l'événement, nous vous donnons accès à un cluster OpenShift préconfiguré, avec la gateway OpenShell déjà en marche. Lors d'un événement multi-utilisateurs, vous recevez un lien de workshop personnel qui vous donne votre propre gateway, votre namespace d'agent et votre namespace de démo sur un cluster partagé. Aucun compte cloud personnel ni carte bancaire n'est nécessaire.

<Callout type="tip" title="Tout est pré-déployé">
Le cluster, la gateway et ce site de workshop tournent déjà. Il vous suffit d'un navigateur pour commencer.
</Callout>

## Ce dont vous n'avez PAS besoin
- D'un GPU : le modèle est servi pour vous (dans ce lab, le modèle `nemotron` servi par OpenShift AI Models-as-a-Service).
- D'une installation locale de Kubernetes/OpenShift : tout tourne sur le cluster.
- D'une connaissance approfondie du YAML : le déploiement tient en un seul Helm chart.
