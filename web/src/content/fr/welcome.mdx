Bienvenue dans le workshop pratique **OpenShell et OpenClaw** proposé par **Red Hat** et **Nvidia**. Pendant l'heure qui vient, vous allez mettre en place votre *propre* agent IA, qui tourne en toute sécurité dans un cluster OpenShift, puis construire quelque chose par-dessus.

Tout tourne sur un cluster OpenShift, **sans GPU sur votre ordinateur portable et sans aucune expérience Kubernetes requise**. Nous fournissons le cluster ; vous apportez un ordinateur portable et un navigateur.

## Comment ça marche

Ce guide est un petit livre organisé en **parties → chapitres**. Les chapitres pratiques intègrent un **shell en direct, dans la page** : quand vous cliquez sur *Exécuter dans le shell*, la commande s'exécute sur votre cluster.

- **Parties I–II** — la plateforme que nous avons préparée pour vous (cluster → gateway OpenShell), et comment la lire
- **Partie III** — comprendre et piloter OpenShell (plan de contrôle + policies) avant de construire
- **Partie IV** — pratique : créer votre propre agent OpenClaw sur la gateway, étape par étape
- **Partie V** — le personnaliser et l'exploiter : identité, dans la sandbox
- **Partie VI** — le hackathon : construire une app **multi-agents** utile

<Callout type="tip" title="Envie de passer vite à la pratique ?">
Survolez les parties I–II (la plateforme tourne déjà) et passez directement à la **Partie IV · Construisez votre agent**. Les chapitres d'architecture sont là quand vous voulez comprendre le <em>pourquoi</em>.
</Callout>
