OpenShift est la **distribution Kubernetes d'entreprise de Red Hat** : Kubernetes, complété de tout ce qu'il faut pour l'exploiter en production (une console intégrée, une configuration sécurisée par défaut, des outils de build et de déploiement, la CLI `oc`). Pour un agent IA, cela se traduit par de vrais guardrails (garde-fous).

## Pourquoi exécuter un agent sur OpenShift ?
- **Isolation par défaut** — les namespaces, le RBAC et les Security Context Constraints limitent ce qu'une charge de travail peut faire.
- **Network policies** — vous pouvez restreindre l'egress de l'agent.
- **Limites de ressources** — des plafonds de CPU et de mémoire empêchent un agent incontrôlable d'accaparer toute la machine.
- **Routes** — chaque service reçoit un vrai nom d'hôte, avec TLS, sans bricolage de ports.
- **Une console** — une véritable interface pour suivre les pods, les logs et les events pendant que vous construisez.
